12. # 1. Data Fundamentals
 
## Structured Data
 
Structured data is data organized into rows and columns with a fixed format.
 
### Examples
 
- Student records
- Payment transactions
- Accounting databases
- Excel spreadsheets

- ## Semi-Structured Data
 
Semi-structured data does not follow a rigid table structure but contains tags, metadata, or key-value pairs.
 
### Examples
 
- JSON files
- XML files
- Emails
- Log files
### Example JSON
 
```json
{
"StudentID": "1001",
"Name": "John Smith",
"Grade": 10
}
## Unstructured Data
 
Unstructured data has no predefined format.
 
### Examples
 
- PDF documents
- Images
- Audio recordings
- Videos
- Social media posts
# 2. Data Storage and Management
 
## Data Lake
 
A Data Lake stores raw data in its original format.
 
### Benefits
 
- Supports structured, semi-structured, and unstructured data
- Low storage costs
- Supports AI and Machine Learning
### Examples
 
- Emails
- PDFs
- Images
- Transaction histories
## Data Warehouse
 
A Data Warehouse stores cleaned and structured data optimized for reporting.
 
### Benefits
 
- Fast reporting
- Better performance
- Trusted business metrics
 
### Examples
 
- Debtor aging reports
- Revenue dashboards
- Financial KPIs
## ETL Process
 
ETL stands for:
 
### Extract
 
Collect data from source systems.
 
### Transform
 
Clean and standardize data.
### Load
 
Store processed data into a Data Warehouse.
 
---
 
## Data Modeling
 
Data Modeling is the process of designing and organizing data structures before implementation.
 
### Types
 
#### Conceptual Model
 
High-level business view.
 
#### Logical Model
 
Detailed data structure.
#### Physical Model
 
Technical database implementation.
 
---

# 4. Artificial Intelligence
 
## What is AI?
 
Artificial Intelligence enables machines to perform tasks that normally require human intelligence.
 
### Examples
 
- Speech recognition
- Decision making
- Language understanding
- Image recognition
## Narrow AI vs General AI
 
### Narrow AI
 
Designed for specific tasks.
 
Examples:
 
- Siri
- Netflix Recommendations
- Chatbots
### General AI
 
Hypothetical AI capable of performing any intellectual task a human can perform.
 
Currently does not exist.
# 5. Machine Learning
 
## What is Machine Learning?
 
Machine Learning allows computers to learn from data without explicit programming.
## Types of Machine Learning
 
### Supervised Learning
 
Uses labeled data.
Examples:
 
- Fraud detection
- Credit scoring
### Unsupervised Learning
 
Uses unlabeled data.
 
Examples:
 
- Customer segmentation
- Market basket analysis
 
---
 
### Reinforcement Learning
Learns through rewards and penalties.
 
Examples:
 
- Self-driving cars
- Robotics
## Deep Learning
 
A subset of Machine Learning that uses Artificial Neural Networks.
 
### Common Applications
 
- Image recognition
- Speech recognition
- Generative AI
## Neural Networks
 
Neural Networks consist of:
 
- Input Layer
- Hidden Layers
- Output Layer

# 9. APIs and Data Exchange
 
## What is an API?
 
An API (Application Programming Interface) allows applications to communicate with each other.
 
### Analogy
 
API = Waiter
 
- Customer = Application
- Waiter = API
- Kitchen = Service Provider
## What is a REST API?
 
REST stands for:
 
**Representational State Transfer**
 
REST APIs typically use:
 
### GET
 
Retrieve data.
 
### POST
 
Create data.
 
### PUT
 
Update data.
 
### DELETE
 
Remove data.
## JSON
 
JSON stands for:
 
**JavaScript Object Notation**
 
Used for data exchange between systems and APIs.
 
Example:
 
```json
{
"Name": "John Smith",
"Balance": 5000
}

## Data Ethics
 
Data Ethics promotes responsible use of data and AI.
 
### Core Principles
 
- Fairness
- Accountability
- Transparency
- Privacy
- Security
 
---
 
## AI Bias
 
AI Bias occurs when an AI system produces unfair outcomes due to biased data or model design.
 
### Example
 
A hiring system trained on biased historical data may unfairly favor certain groups.
 
### Consequences
 
- Discrimination
- Legal risks
- Loss of trust
